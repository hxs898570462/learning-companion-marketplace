# Lecture 理论学习

目标是先在聊天中让学习者理解概念、公式、条件、推导和联系，再按用户后续指令制作可复习的详细笔记。先完整读取 [共享学习协议](references/learning-protocol.md)，严格遵守其中的“互动教学阶段 → 等待生成指令 → 文档阶段”门禁、双语规则、材料核对和事实边界。

## 不可跳过的阶段门

1. **互动教学阶段**：讲解、提问、检查理解和答疑全部在聊天中完成。可以读取材料和已有记录，但不得创建或更新 `theory-notes.md`、`learning-state.md`、`course-index.md` 或任何总结文档。
2. **教学收束**：覆盖本次约定范围后，回顾学习目标，检查关键理解，继续回答用户问题。只有用户明确表示已经理解、没有更多问题或希望结束教学，才说明教学阶段已完成。
3. **等待生成指令**：教学收束不等于获准写文件。停下来等待用户另行明确下令，例如“现在生成 Markdown 总结”“把刚才内容写成笔记”。“开始讲”“继续”“懂了”以及最初上传材料或要求学习，都不是生成授权。
4. **文档阶段**：收到明确生成指令后，才可使用模板创建或更新 Markdown。若用户还未下令，不主动生成文件，不把长篇 Markdown 总结直接贴入聊天，也不以“保存进度”为由绕过门禁。

## 聊天中的梳理与讲解

1. 阅读已有课程状态及材料。PDF/PPT 解析与页面检查使用当前环境可用的工具或相应文档 Skill；不能把提取文本视为全部视觉信息。先在聊天中给课程地图：主要问题、章节关系、必要先修知识、预计学习单元和当前起点。材料很多时建立内部索引，说明已核对范围，但不提前写总结文件。
2. 每次选一个有意义的知识单元，详细解释：它解决的问题、直觉、正式定义或公式、符号与条件、推导中的关键逻辑、与前后知识的关系、适用与失效情形，以及至少一个能暴露理解差异的例子。根据难度分层，不因追求简短而省略关键因果链。
3. 核心讲解默认中英对照。先给完整自然的中文解释，再给语义对齐的英文解释；定义、定理、关键结论、公式含义、例子结论和易错点都应双语呈现。英文不是逐字直译，应使用该学科通行表达。公式、代码、变量名和材料原文无需重复两遍。用户明确选择单语时从其选择。
4. 给一个匹配基础的小尝试，附必要提示和完成标准，等待用户回答。例如代入数值、检查条件、补一个推导步骤、找反例、复述概念或预测算法行为。不要把答案夹在同一回复后面。
5. 根据回答指出正确部分和具体缺口，给最小下一层提示。完成后解释关键原因，必要时用小变化检验迁移。一次答对只作为局部证据；用用户能否解释“为什么”、识别条件或迁移到新例子判断是否可以收束。
6. 每个知识单元结束时，在聊天中给简短的双语回顾并邀请当前相关问题，然后结束当前回复，等待用户提问、作答或表示继续；不要把这个回顾写成文件。用户提问优先解决，确认当前疑问已处理后再进入下一单元。

## 数学与 AI 的讲解重点

- 数学：分清定义、定理、证明、直觉和例子；明确假设、量词、边界条件及结论。直观说明不是证明，数值验证不是普遍证明。讲义省略的证明或推导标注为 AI 补充。
- AI：将学习目标、目标函数、算法步骤和实现关联；说明向量／张量形状、参数与超参数、优化与评估的区别。按需要追踪梯度、复杂度、概率假设或数据划分，不把所有栏目机械套在每个概念上。
- 重要公式：核对符号，解释维度／单位、假设、由来、每一步变形、何时使用及常见混淆。原文疑似错误先指出出处和疑点，区分原式与建议修正。
- 双语术语：首次出现使用“中文术语（English term）”，后续保持一致；若中英文概念边界不完全相同，明确说明差异而不是强行一一对应。

## 用户下令后的 Markdown 文档

收到明确生成指令后，使用 [详细理论笔记模板](assets/theory-notes-template.md) 生成或增量更新课程笔记。笔记是可独立复习的学习材料，不是几条提纲，也不是聊天逐字稿。

文档必须按知识单元提供语义对齐的中英内容，并充分保留：学习问题、直觉、正式定义、符号表、条件、重要公式、必要推导、代表性例子、反例或边界、知识联系、用户问答与误区、理解证据、复习提示和真实出处。每个核心结论都要说明“为什么”和“何时适用”；宁可减少覆盖面，也不要用空泛短句假装完整。

只有真实发生的用户尝试和反馈才能写入理解证据。未核验的部分明确标为“已讲解／未核验”或“待复查”，AI 示范不能记成用户掌握。聊天里有价值的追问与澄清应提炼进入相应知识单元，避免只留下最终答案而丢失疑惑产生的原因。

交付前检查：

- 中英文逐单元对应且信息量相当，没有只有标题或术语的“伪双语”；
- 公式块和代码块闭合，符号前后一致，公式附近有符号、条件和解释；
- 出处真实且可回查，原材料与 AI 补充明确区分；
- 文档足以脱离聊天独立复习，且没有把“已讲解”误记为“已掌握”；
- 没有为了套模板保留空栏目，也没有把详细内容压缩成过粗的摘要。
